# Create Your Own Sites — портфолио

Статический сайт для GitHub Pages. Без сборки, установки библиотек и платного сервера.

Почта: createyourownsites@gmail.com
Аккаунт: https://github.com/createyourownsites-glitch
Адрес после публикации: https://createyourownsites-glitch.github.io/

## Локальный просмотр

Из этой папки выполните `python -m http.server 8080`, откройте http://localhost:8080/.
Используйте HTTP-сервер: проекты содержат JavaScript-модули.

## Публикация через браузер

1. Создайте публичный репозиторий с точным именем `createyourownsites-glitch.github.io`.
2. Загрузите содержимое этой папки в корень репозитория: index.html должен лежать сразу в нём,
   рядом с styles.css, script.js, .nojekyll, assets и projects. Вложенную папку portfolio-github не добавляйте.
3. В Settings → Pages выберите Deploy from a branch → main → /(root) → Save.
4. Дождитесь успешного завершения Pages build and deployment. Откройте адрес сайта выше.

Для обновления заменяйте файлы в том же репозитории. Не загружайте базу компаний,
парсер, node_modules, тесты или данные клиентов — здесь уже только публичные файлы портфолио.

Перед публикацией после изменений HTML, styles.css или script.js выполните
`python prepare_assets.py` и добавьте созданные styles.<хеш>.css и script.<хеш>.js
вместе с обновлённым index.html в коммит. HTML подключает именно эти версии:
браузер не подставит старый CSS/JS из кэша под новый макет. Старые версии не удаляйте,
пока они могут использоваться ранее сохранённым HTML. styles.css и script.js остаются
исходниками для редактирования. Если содержимое не менялось, имена версий сохраняются.

## Проекты

- projects/nude — NUDE, пространство красоты (исходная папка dist).
- projects/stroim-dom — модульные дома.
- projects/avtomedik — автосервис (исходная папка auto-service/site).
- projects/wood — мебельная фабрика Вуд (исходная папка salon).
- projects/emal — «Эмаль», стоматология: услуги, специалисты и демо-запись.
- projects/kuhnya-ryadom — «Кухня рядом», кафе: меню, корзина, демо-заказ.

Оригиналы на рабочем столе не изменяются. Для публикации используются отдельные копии.
Относительные пути работают как на главном домене Pages, так и во вложенном репозитории.
Формы в демонстрациях не отправляют заявки. Пометка об этом и ссылка возврата добавлены
через assets/demo.js. Калькуляторы, каталог, меню и остальные локальные функции сохранены.
Проекты обозначены демонстрационными; опубликованные в них цены и показатели — часть демо.

## Где менять содержание

- index.html — тексты портфолио, карточки проектов и контакты.
- styles.css — оформление и адаптация.
- script.js — фильтры и копирование email.
- assets/previews — реальные снимки первых экранов проектов.
- assets/previews/*-mobile.jpg — реальные снимки мобильных версий для мокапов.
- assets/social-preview.jpg — обложка для ссылки в сообщениях.

Контакты и отзывы внутри демонстрационных проектов не являются контактами портфолио.
Для связи используйте createyourownsites@gmail.com на главной странице.

## Оформление портфолио

Яркая галерея с синим первым экраном, коллажем сайтов, шестью работами, асимметричной сеткой
и отдельной палитрой каждого проекта. В карточках показаны настольная и мобильная
версии. Все служебные подписи набраны обычным читаемым шрифтом. Движение мокапов
отключается при prefers-reduced-motion. Фильтры и ссылки на демо работают с клавиатуры.

## Новые демонстрации

«Эмаль» использует бело-синюю палитру, тематические изображения услуг и форму
с выбором услуги, специалиста и даты в ближайшие три месяца. Дата не бронируется,
личные данные не сохраняются и не отправляются. Специалисты и адрес вымышлены.

«Кухня рядом» оформлена в тёплой молочной палитре с графитовым и горчичным акцентами.
Меню фильтруется по категориям; состав и аллергены раскрываются в карточке.
Корзина хранит в localStorage только идентификаторы блюд и количество (не больше
20 порций одного блюда), восстанавливается после обновления и синхронизируется
между вкладками. Повреждённые или неизвестные значения отбрасываются.
Самовывоз бесплатный; пример доставки стоит 200 ₽, от 1500 ₽ бесплатно.
Имя, телефон, адрес и комментарий не сохраняются и не передаются. Оформление
показывает демонстрационное подтверждение и очищает корзину; оплаты и реального
заказа нет. Для рабочего кафе потребуются обработчик заказов, актуальные условия
доставки, реальные контакты и платёжная интеграция при необходимости.

`python prepare_assets.py` обновляет версии CSS/JS обеих новых демонстраций,
включая импорт модуля корзины. Исходники: style.css, app.mjs, order.mjs.
Не редактируйте файлы с хешем вручную. Новые изображения созданы для концептов;
исходники сгенерированных изображений хранятся за пределами публичного репозитория.
Локальные шрифты Manrope и Golos Text распространяются по OFL; лицензии рядом
с файлами в assets/fonts. Внешние CDN, аналитика и сторонние формы не используются.
